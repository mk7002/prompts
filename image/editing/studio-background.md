# Studio Background

## Description

Replace only the background of a portrait with a clean studio backdrop while keeping the person completely unchanged and naturally lit.

## Prompt

> Replace only the background with a [soft / smooth / textured] [color, e.g. beige / light gray / white / navy] studio [gradient / solid backdrop / seamless paper backdrop].
>
> Keep the person's face, hair, skin tone, outfit, body, pose, and expression unchanged.
>
> Match the new background lighting to the existing lighting on the person so the final image looks naturally photographed.

## Use Cases

- Professional headshots and profile pictures
- LinkedIn, resume, and ID-style photos
- Consistent backgrounds for team or staff photos
- Cleaning up portraits taken against busy backgrounds

## Notes

Replace the bracketed placeholders. Example: "a soft beige studio gradient". Neutral, warm tones such as beige or light gray flatter most skin tones. If the new background doesn't blend well around hair edges, ask for a refinement pass on the hair edges. For non-studio scenes, use [Background Replacement](./background-replacement.md).
