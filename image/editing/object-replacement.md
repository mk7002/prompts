# Object Replacement

## Description

Replace a selected object with a different one while keeping the rest of the image unchanged.

## Prompt

> Replace the selected object with the requested replacement while preserving the rest of the image. Match the replacement object's scale, perspective, lighting, shadows, reflections, texture, and position so it looks naturally captured in the original scene. Do not alter unrelated elements or the main subject.

## Use Cases

- Swapping products, furniture, or decor in a scene
- Changing clothing items or accessories
- Updating signage, screens, or props
- Visualizing design or layout alternatives

## Notes

Select or mask the object to replace and describe the replacement clearly (type, color, material, style). A reference image of the replacement object helps.
