# Background Replacement

## Description

Swap the background for a new scene while keeping the main subject unchanged and realistically integrated.

## Prompt

> Replace the selected background with the requested background while keeping the main subject completely unchanged. Preserve the subject's face, hair, body, clothes, pose, proportions, expression, and position. Match lighting, perspective, scale, shadows, reflections, depth of field, and color temperature so the subject naturally belongs in the new environment.

## Use Cases

- Placing a subject in a new location or setting
- Creating studio-style or plain backgrounds for profile photos
- Producing product shots on custom backdrops
- Replacing dull or overexposed skies

## Notes

Describe the new background specifically (location, time of day, lighting, mood). Supplying a reference image of the target background improves consistency. Watch fine edges such as hair and transparent objects. For plain studio backdrops behind a portrait, see [Studio Background](./studio-background.md).
