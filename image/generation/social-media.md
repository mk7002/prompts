# Social Media Image

## Description

Generate eye-catching images optimized for social media posts, stories, and thumbnails.

## Prompt

> Create an eye-catching image for [platform, e.g. Instagram post / story / YouTube thumbnail / LinkedIn banner] about [topic or message]. Use a [aspect ratio, e.g. 1:1 / 9:16 / 16:9] format.
>
> Feature [main subject or visual concept] as a clear focal point that reads well at small sizes. Use a [mood, e.g. bold and energetic / calm and minimal / professional] visual style with a cohesive color palette of [colors or brand colors].
>
> Leave clear space for a headline or text overlay in [position]. Keep the design uncluttered with strong contrast. Avoid generated text, watermarks, or distracting background details.

## Use Cases

- Instagram posts and stories
- YouTube thumbnails
- LinkedIn and X/Twitter banners
- Promotional and announcement graphics

## Notes

Add text in a design tool afterward, because generated text is often misspelled. Check each platform's recommended dimensions before generating.
